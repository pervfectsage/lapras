# Lapras
An original, buildless classroom interface around js-dos 6.22 and a user-supplied Turbo C++ DOS distribution.

Serve `dist/` over HTTP. Launch the IDE, click its canvas to capture keyboard input, compile/run with the toolbar or classic shortcuts. Source-panel drafts persist locally; IDE changes must be saved with F2, read into the panel, and downloaded to preserve them outside the session.

This is an owner-private prototype. Browser execution and graphics still require manual acceptance testing. Borland redistribution rights are unverified; do not make the supplied compiler package public without establishing rights. Emulator licence and upstream source links are in `dist/notices.html`.

The compiler archive contains DOS binaries, headers, libraries, and BGI drivers from the supplied ZIP. Windows installers, desktop launchers and swap files are excluded. C:\TC include/library aliases accommodate legacy IDE directory settings.
